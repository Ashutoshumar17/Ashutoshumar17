# 🚀 Featured Projects

### [AudioDSP-HearingAid](https://github.com/Ashutoshumar17/AudioDSP-HearingAid)
**Python · Digital Signal Processing · Streamlit**

A digital audio-processing project focused on hearing-aid concepts, with audio filtering and signal analysis. It connects software implementation with core ECE topics such as digital signal processing, frequency response, FFT, and spectrograms.

### Cloud-Integrated Smart Attendance System
**FastAPI · AWS EC2 · MongoDB Atlas · JavaScript · REST API**

A client-server attendance application with a FastAPI REST API deployed on AWS EC2 and MongoDB Atlas for data storage. Features include WebRTC camera streaming, audit logging, an admin dashboard, attendance summaries, absence calculations, and CSV reports.
