# ☁️ Featured Project:
**Cloud-Integrated Smart Attendance System** — FastAPI, AWS EC2, MongoDB Atlas, JavaScript, REST API<br>
Client-server web app with a FastAPI REST API deployed on AWS EC2 (Windows Server). MongoDB Atlas uses a compound unique index on `{student_id, session_id}` to enforce idempotent check-ins. Includes WebRTC camera streaming, audit logging, and an admin dashboard with live attendance ratios, absence calculations and CSV reports.
